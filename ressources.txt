# RESSOURCES de l'appli Corde à Trois Fils
#
# Une ligne = une ressource. Les cinq parties sont séparées par une barre verticale | :
#
#   Rubrique | Titre | Auteur ou intervenant | Quelques mots de présentation | Lien (facultatif)
#
# - La rubrique est libre : Livre, Podcast, Enseignement... Chaque rubrique différente crée un filtre dans l'appli.
# - L'auteur, la présentation et le lien peuvent rester vides, mais gardez les barres | à leur place.
# - Le lien doit commencer par https:// (page du livre, épisode du podcast, vidéo de l'enseignement).
# - Les lignes qui commencent par # ne s'affichent pas. Les ressources apparaissent dans l'ordre du fichier.
#
# Les lignes ci-dessous sont des exemples pour montrer la forme : remplacez-les par vos recommandations.
